# Contributing

1. Open an issue describing the change.
2. Keep provider capabilities evidence-backed.
3. Add tests for new behaviour.
4. Run `npm run typecheck`, `npm test`, and `npm run build`.
5. Never commit credentials, generated private media, local databases, or `.env` files.
6. Do not add undocumented Meta endpoints or unauthorized automation.

All contributions are subject to the Apache-2.0 licence.
